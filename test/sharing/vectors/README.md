# Sharing vectors (cross-SDK)

Generated by `node scripts/sharing-vectors.mjs` in quranlab-local (`--check` compares). The spec is
PLATFORM_CLIENT.md sections 9 and 10 of the V4 launch.

- `signing.json`: the deletion message (byte exact), a fixed P-256 key (test only, never use it), and
  signatures over each message (r||s and DER, base64url) that verify with its public key.
- `recovery.json`: recovery codes from fixed bytes, typed spellings and their normalised form, and the
  `recovery_hash` sent with the first session.
- `ogg/`: one session muxed from deterministic packets (see `expected.json` `about`): every SDK's muxer,
  fed those packets, writes these four segment files byte for byte. `npm run e2e:client` uploads them to
  the local stack, whose consumer accepts them as one complete session.
